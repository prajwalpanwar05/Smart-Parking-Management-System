# Smart Parking Management System

A Software Engineering case study focused on the analysis and design of a **Smart Parking Management System**.

## 📌 Project Overview

The Smart Parking Management System aims to make parking management more organized and efficient. This project explores how a software-based system can help manage parking spaces and improve the parking experience for users.

This repository contains the Software Engineering Project-Based Learning (PBL) case study report.

## 🎯 Objectives

- Study the concept of a Smart Parking Management System.
- Understand the requirements of a parking management solution.
- Explore software engineering principles and system design.
- Prepare project documentation as part of the BCA curriculum.
